napari-virtual-reader / general workflow

Keep the pixels in the original file.

Build a virtual OME-Zarr view, then decode source regions when napari requests them.

Open path

Raw images and archives meet at the same reader.

The reader discovers OME-Zarr image groups, maps axes and transforms, and creates a layer per acquisition channel. It preserves stored pyramid levels. It does not create missing resolution levels by downsampling.

Why CZI needs an extra path

refkv can expose irregular or overlapping CZI tiles separately from its regular image levels. Reading only those levels can omit native resolution or show just an overview.

The CZI assembler uses tile coordinates and resolution factors to expose those pieces as aligned image levels. Placement restores the missing view; lazy chunk reads avoid materializing the whole slide. Laziness alone does not solve tile placement.

CZI-only assembly. Other formats bypass this extra path. They can still display images and pyramids already exposed by refkv, but this plugin does not yet assemble their separate irregular tile arrays.

Colour is not a channel count

CZI packed BGR(A) samples become one RGB(A) layer. Codec-aware ordering retains already-decoded RGB. Scalar fluorescence channels stay separate.

Scenes can share a slider

Compatible CZI scenes stack along S. Different shapes, scales, dtypes, axes or level counts stay separate. Original scene transforms remain in metadata.

Registered filename extensions offer the reader; they do not guarantee that refkv can parse the file or decode its codecs.

The Zarr tree describes the original reference store. For an assembled CZI, the displayed mosaic can have different shapes and levels; inspect czi_assembly as well.

Persistence

A VZIP saves the map, not the image pixels.

Choose the original CZI for mosaic assembly. Reopened VZIPs may show only regular levels and warn about remaining tiles. Source access must also be permitted by refkv's policy.

Saving stages the archive before publishing it. Replacing an existing destination requires confirmation; a failed write preserves the old archive. Cancelling the save dialog cancels that open action.

Boundaries

Lazy does not mean every file is complete.

Supported 2D CZI mosaics use deterministic tile placement, not registration or blending. This plugin does not use czitools or libCZI as a fallback.

The incomplete-tile warning is also CZI-specific. No warning for another format is not proof of a complete view.

Remote inputs, non-image tables, arbitrary tensors and stores without OME image metadata are outside the current reader scope. Decode errors propagate; zero-filled mosaic gaps are not an error-recovery mechanism.

Experimental software. Validate scientific results independently, especially overlap regions and views with warnings.
